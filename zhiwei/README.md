# 知微 · 早产风险监测平台（框架）

本仓库包含 Electron + React + TypeScript 的“知微”核心框架，覆盖孕妇端、家属端与医生端的基础界面与数据结构。

## 本地启动

```bash
npm install
npm run dev
```

## 如何切换三端

- 登录后，顶部标题栏右侧的 **「孕妇端 / 家属端 / 医生端」** 切换器可随时切换视角。
- 切换后，左侧导航会同步切换为对应角色的页面。

## 如何触发 8 种 Mock 场景

- 进入孕妇端首页 `首页状态`。
- 在 **“Mock 演示”** 卡片里选择 1-8 号剧本。
- 选择后页面会显示当前剧本名称，用于讲解不同风险阶段。

## 如何演示家属协作流（场景 7 完整步骤）

1. 在孕妇端首页选择 **“7. 家属协作流”** 剧本。
2. 切换到家属端 → 进入「协作主页」，查看已确认/在路上的协作状态。
3. 打开「团队管理」确认成员分工与通知策略。
4. 在「紧急响应」页演示倒计时呼叫按钮。

## 如何演示医生覆盖流（场景 8 完整步骤）

1. 在孕妇端首页选择 **“8. 医生覆盖流程”** 剧本。
2. 切换到医生端 → 进入「患者列表」，点击任意患者的 ⓘ 图标。
3. 打开「医生覆盖」页，演示填写临床理由并提交覆盖。
4. 切换到「算法反馈」页，展示覆盖记录进入反馈队列。

## 如何演示记忆模式

- 在孕妇端首页或「设置」页找到 **记忆模式** 卡片。
- 点击 **“进入静默模式”** 按钮即可进入记忆模式。
- 退出模式可点击 **“恢复常规模式”**。
